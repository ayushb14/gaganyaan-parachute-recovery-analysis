# Final Table Data Folder

This folder contains all table-based outputs collected from the MATLAB–OpenFOAM parachute descent simulation workflow.

## Folder contents

## 01_stagewise_cd_tables
Stage-wise drag coefficient outputs from OpenFOAM post-processing.

## 02_matlab_openfoam_coupled_profile
Coupled MATLAB–OpenFOAM stage profile linking descent assumptions with CFD-derived aerodynamic coefficients.

## 03_monte_carlo_tables
Monte Carlo uncertainty-analysis CSV outputs, if available.

## 04_openfoam_force_coefficients
Raw and cleaned OpenFOAM force coefficient histories for each parachute stage.

## 05_matlab_raw_tables
Raw MATLAB output tables copied from the MATLAB simulation folders.

## 06_openfoam_raw_tables
Reserved for additional OpenFOAM raw tabular outputs.

## 07_report_ready_tables
Cleaned tables directly usable in the final report.

## 08_logs_and_mesh_quality
OpenFOAM logs and mesh-quality outputs.

## 09_all_csv_backup
Single backup folder containing all CSV files copied from different sources.

## MASTER_TABLE_INDEX.csv
Index of all table/data files collected in this folder.
